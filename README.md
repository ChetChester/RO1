# 諸神放置錄 — RO 風放置冒險（雛型 v0.1）

以《仙境傳說 Ragnarok Online》的職業轉職系統為核心賣點打造的放置型網頁遊戲。
純 HTML / CSS / JS，無需建置工具，雙擊 `index.html` 或用任一靜態伺服器開啟即可遊玩。

## 怎麼玩
1. 開啟 `index.html`，選擇「開創新的旅程」建立角色（分配六圍屬性點）。
2. 進入遊戲後會自動在新手訓練場對戰，經驗值、金錢、掉落物全自動累積。
3. 升到基礎等級 10 + 職業等級滿(10) 後，右側「🔔 可以轉職了！」會亮起，
   到「轉職樹」分頁點擊發光節點完成一轉。
4. 一轉後有專屬主動技能（技能分頁習得），可手動點擊施放，或勾選地圖分頁的
   「自動施放技能」讓角色離線時也會自動使用技能戰鬥。
5. 二轉門檻：基礎等級 40 + 職業等級滿(40)。

## 已完成
- 六圍屬性系統（STR/AGI/VIT/INT/DEX/LUK）與衍生戰鬥數值，**創角單項屬性上限 9 點**
- 新手 → 六個一轉職業（劍士/法師/弓箭手/商人/盜賊/見習修女）
  → 六個代表性二轉職業（騎士/巫師/獵人/鐵匠/刺客/祭司）
- 自動戰鬥、被動回血回魔、技能主動/自動施放、buff/dot 系統
- 4 張地圖（新手訓練場→普隆德拉草原→培恩森林→半獸人村落），依等級解鎖
- 裝備／消耗品／素材道具、簡易背包與販售
- 轉職樹視覺化畫面（金色路徑連接已走過/可走的職業節點）
- **離線掛機系統**：關閉分頁/瀏覽器期間，角色仍會依目前所在地圖持續戰鬥，
  重新打開時結算離線期間的經驗值、鋅幣與掉落物（上限 12 小時，離線超過 30 秒才會結算）
- **RO Renewal 風格戰鬥公式**（參考 [landgris ROCalculator](https://landgris.github.io/ROCalculator/) 調整而來，非逐位元還原）：
  - ATK = STR + (STR/10)² + DEX/5 + LUK/5（StatusATK 公式）
  - MATK 採區間值（min~max），INT 為主、DEX/LUK 為輔
  - HIT = 175 + 基礎等級 + DEX，FLEE = 100 + 基礎等級 + AGI（經典命中/迴避公式）
  - 命中率% = 100 + 攻擊方HIT − 防守方FLEE（夾在 5%~100%），越級挑戰會有真實的落空風險
  - 新增**完全迴避**（LUK/10 %，直接無視命中判定）與**暴擊**（無視閃避判定，傷害×1.5）
  - DEF 改為**比例減傷**（reduction = DEF/(DEF+60)）取代直接相減，避免高防怪變成零傷害
  - 200 等後才開放的四轉「特質點」(POW/STA/WIS/SPL/CON/CRT) 屬於很後期內容，這次先不導入
- **官方素質點數規則**（對照巴哈姆特/RO Wiki 公開的正式版數值表校正）：
  - 每級獲得屬性點 = floor((等級-1)/5) + 3（36級每級10點、41級每級11點...，與官方對照表逐級核對一致，99級累積 1225 點與官方數字相符）
  - 加點消耗隨數值升高遞增 = 2 + floor((目前數值-1)/10)（1~10 花2點、11~20花3點、21~30花4點...與官方 2~11/12~21 對照表一致），角色分頁的 + 按鈕旁會顯示下一點的花費
  - 六大二轉職業的 HP/SP 職業係數也依公開資料校正（騎士1.5/3、巫師0.55/9、祭司0.75/8、刺客1.1/4、鐵匠0.9/4、獵人0.85/4，依比例套入本作公式），巫師/祭司因此變得更脆但SP更充沛，更貼近正式版的職業特色
  - 順手修正一個 bug：祭司/見習修女等魔攻型職業先前普通攻擊誤用物理ATK計算，導致幾乎打不動，已改為依職業 matkMod/atkMod 高低自動判斷攻擊模式
- **地圖系統重新設計**（參考 [仙境全書地圖資料](https://ro.ntome.com/map/world) 與 [Divine Pride 怪物資料庫](https://www.divine-pride.net/database/monster) 校正）：
  - 每個城鎮改為「城鎮周邊」+「原野」兩張地圖可選（例如普隆德拉 / 普隆德拉原野），共 4 座城鎮 7 張地圖（新手訓練場、普隆德拉、普隆德拉原野、培恩、培恩原野、摩洛克、摩洛克沙漠）
  - 怪物**遇怪機率採真實地圖密度權重**：例如普隆德拉原野對應真實地圖 prt_fild08 的怪物密度（波利70/幼蟲77/瘋兔67/蛹20），培恩原野對應 pay_fild01（孢子密度高達100，是該地圖的主力怪），摩洛克沙漠對應 moc_fild02（波利波利鳥為主）
  - 新增 6 種怪物：蛹、柳精、孢子、波波利、波利波利鳥、小雞（等級/強度依本作既有戰鬥公式內插校正，非直接套用官方數值，因為我們的等級節奏與官方不同）
  - 城鎮周邊怪物密度低、種類少（安全悠閒），原野怪物種類多、遇怪率高（主力練功區）
- **普隆德拉地區完整展開**（參考 rAthena 開源伺服器怪物出生資料 `npc/pre-re/mobs/fields/prontera.txt`）：
  1 座城鎮 + 12 張原野（對應真實 prt_fild00~11），新增 21 種怪物，全區怪物總數來到 34 種。
  怪物 **HP/ATK/DEF/經驗值改採官方數值**（等級與經驗值直接取自官方公開資料，HP/ATK/DEF依官方經典數值填入），
  不再是本作自行內插校正的數字 —— ⚠️ **這一輪先求數值真實，尚未考慮與玩家數值曲線的平衡，
  部分原野（尤其蠻荒之地／哥布林前哨）用官方數值後會明顯偏強，需要後續再做一輪平衡調整**
  - 稀有裝飾系怪物（綠精/藍精/閃光精靈/黃精/紅菇/黑菇/日蝕/裝甲哥布林）保留，以低權重穿插在各原野中
- **地圖選單改為兩個下拉選單**：第一個選地區（新手教學區/普隆德拉/培恩/摩洛克，標示官方全名副標題
  例如「盧恩 米德加茲王國首都普隆德拉」），第二個選該地區的城鎮／原野。**城鎮是安全區、完全沒有怪物**
  （離線掛機在城鎮也只是安穩休息、不會有戰鬥收穫），原野才會遇怪。**不設任何等級限制**——想去哪就去哪，
  越級挑戰（甚至因此陣亡）也是探索的一部分樂趣，畫面上只會提示風險、不會阻止你
- **HUD 右上角手動存檔按鈕**（💾 儲存），亦保留自動存檔（每 5 秒節流）與關閉分頁時自動存檔
- **三種等級藥水**（紅/橘/白）＋自動使用／不足自動購買：
  - 創角贈送紅色藥水 x100
  - HP 低於 50% 時自動使用背包分頁選定等級的藥水（可切換）
  - 選定藥水用完時，若「藥水不足自動購買」勾選中，會自動花鋅幣購買 100 瓶（金錢不足則買到能力所及的數量）
  - 背包分頁也可手動購買/使用/販售各等級藥水
- **圖片資料夾系統**：怪物/道具/武器/防具都給了仿RO慣例的數字編號（imgId），
  對應資料夾已預先放好「佔位圖」（標示分類/編號/英文代號），把你的美術圖用
  相同檔名覆蓋進去就會自動生效，找不到圖時自動退回通用預留圖不會壞版面。
  詳見 `images/README.md`。
- **地圖底圖 + 背景音樂**：4 張地圖也都有專屬編號（5001~5004），對應
  `images/maps/{編號}.png`（已有佔位底圖）與 `music/maps/{編號}.mp3`（自己放，
  沒放就安靜不播放，不會報錯）。切換地圖時背景圖與音樂會自動一起換，畫面
  右上角有 🔊 靜音鈕。詳見 `music/README.md`。

## 資料驅動架構
所有遊戲內容集中在 `js/data.js`：
- `JOB_TREE`：職業節點（含 `parent`/`next` 建立樹狀關係、`skills` 技能定義）
- `MONSTERS` / `MAPS` / `ITEMS`：怪物、地圖、道具表

`js/engine.js` 只讀取資料驅動邏輯，不寫死任何職業/怪物名稱，之後要擴充內容
（新增職業、怪物、道具、地圖）只需要在 `data.js` 加資料，不太需要動引擎邏輯。
